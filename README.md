
Ce système complet implémente un langage de modélisation de réseaux épidémiologiques avec :

1. **Grammaire complète** avec ANTLR pour la définition du langage
2. **AST (Abstract Syntax Tree)** pour la représentation interne
3. **Système de types** pour la vérification statique
4. **Table des symboles** pour l'analyse sémantique
5. **Optimisations** pour améliorer les performances
6. **Représentation intermédiaire (IR)** pour l'analyse et l'optimisation
7. **Générateurs de code** pour Python, Julia et C++
8. **Interface CLI** pour la compilation et l'exécution
9. **Exemples complets** de modèles épidémiologiques
10. **Importation de données** depuis CSV, JSON, SQL

Le système supporte les fonctionnalités :
- Modélisation de réseaux complexes
- Calcul automatique de R0
- Analyse de sensibilité
- Importation de données réelles
- Génération de code multi-langage
